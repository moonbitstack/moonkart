Put one in, then click a card in the box to ask for it again.

01 / CAPACITY

Bounded

Cap by entry count with cap, or by total size with max_weight and a weigher when values differ.

02 / TIME

Expires

Time to live, time to idle, or a rule of your own, per entry. The clock is a parameter, so a test moves a number instead of sleeping.

03 / LOADING

Loads once

Readers of the same missing key wait for one loader and share its answer. If it raises, every reader gets that error and nothing is stored.

04 / POLICY

Swappable

W-TinyLFU by default, LRU and S3-FIFO when you want them, and your own behind the same contract. The cache type never changes.

THE SAME THREE CALLS, ON A BOX THAT HOLDS TWO

let cache = @moonkart.lru_cache(cap=2L)
cache.set("a", 1)
cache.set("b", 2)
cache.get("a")      // "a" is now the most recent
cache.set("c", 3)   // full: "b" leaves

WHAT IT PRINTS

a is present: true
read a: 1
b survives: false
c is present: true
hits: 1, misses: 0
evictions: 1
